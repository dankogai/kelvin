# The C contract

What a Kelvin program becomes in C (#208): the form of the file, the
names, the types and their functions, and how it is built. kelvinc
writes it, and so must any other compiler of Kelvin, as
[selfhost/kc.k](../selfhost/README.md) does, for its C to meet the
runtime, `kelvin_prelude.h` and `libkelvin`, and the modules kelvinc
builds.

**Where it lives:** the core. It is what `kelvinc --emit-c` shows, and
what `modules/kelvin_prelude.h` declares. Nothing here is a promise
beyond the version it describes; it is *provisional*, as the rest of
Kelvin is, and a change to it is a change of its own.

## The file

```c
/* generated by kelvinc */
#if !defined(__FreeBSD__) && !defined(__NetBSD__) && !defined(__OpenBSD__) && !defined(__DragonFly__)
#ifndef _XOPEN_SOURCE
#define _XOPEN_SOURCE 700
#endif
#ifndef _DEFAULT_SOURCE
#define _DEFAULT_SOURCE 1
#endif
#endif
#ifndef _DARWIN_C_SOURCE
#define _DARWIN_C_SOURCE
#endif
#include <stdbool.h>
#include <stdint.h>
#include <string.h>
#include <kelvin_prelude.h>
```

- **The feature macros** come first, so that a header imported as C
  shows POSIX and the system's own functions (#176); the BSDs get none,
  since there they hide more than they show (#192).
- **Then, in the order of the source:**
  - `#include <kOS.h>` and `#include <kIO.h>` for `#import <IO>`, the C
    header of each module imported (#143, #144);
  - `#include <x.h>` for `#import <x.h> as C`;
  - an `#inline C { ... }` as it is written (#197);
  - the declarations, each where the source has it.
- **Before them,** the prototypes kelvinc needs early: the printers of
  the types `print` shows (`_kv_show_T`), and `_kv_free_globals`.
- **`#line`** maps each statement to the `.k` file and line, so that
  the C compiler's messages name the source; `--emit-c` shows them.

## Building

What `kelvinc -v` shows, for a program that imports `<IO>`:

```sh
cc -std=c11 -O0 -g0 -Wno-unknown-warning-option -Wno-pointer-sign \
   -Wno-incompatible-library-redeclaration -Wno-builtin-declaration-mismatch \
   -Wno-psabi -ffp-contract=off -I. -isystem <modules> -L<modules> \
   -o program program.c <modules>/libkIO.a <modules>/libkOS.a <modules>/libkelvin.a -lm
```

- **C11 with GNU C's extensions,** which gcc and clang have:
  - statement expressions, `({ ...; v; })`, for a value made of
    statements;
  - `__attribute__((cleanup(f)))`, for freeing an owner where its block
    ends;
  - `__auto_type` and `__typeof__`, for a temporary of what an
    expression gives;
  - `__int128`, for `i128` and `u128`.
- **`_Generic`,** C11's, chooses a function by a value's type:
  `println`, `KV_STRING_APPEND`, `KV_STRING_OF`, and a method that only
  C sees.
- **The warnings off:** `uint8_t` text beside C's `char` text
  (`-Wno-pointer-sign`), and Kelvin's overloads of C's own functions.
- **`-ffp-contract=off`:** no fused multiply-add, so that a float
  computes the same with every compiler.
- **The libraries,** after the program, as a library must be on Linux:
  - each module's `libkM.a` (or `.dylib` and `.so`, #147), a module
    before the modules it imports: `libkIO.a`, then `libkOS.a`;
  - `libkelvin.a`;
  - `-lm`;
  - and `KELVIN_CFLAGS`, after them all (#46).

## Types

| Kelvin | C |
|---|---|
| `i8` ... `i64`, `u8` ... `u64` | `int8_t` ... `int64_t`, `uint8_t` ... `uint64_t` |
| `i128`, `u128` | `__int128`, `unsigned __int128` |
| `f32`, `f64` | `float`, `double` |
| `bool` | `bool` |
| `cstr` | `const uint8_t *` |
| `T^` | `T *`; a `let` parameter is `T *const` |
| `[T](n)`, `[T]` | `T[n]`; `T *` as a parameter |
| `(A, B):R` | `R (*)(A, B)` |
| `uchr` | `kv_uchr`, `struct kv_uchr { uint32_t cp; }` |
| `Bytes` | `kv_bytes`, `struct kv_bytes { uint8_t *at; size_t count, cap; }` |
| `String` | `kv_string`, `struct kv_string { kv_bytes b; size_t count; }`: UTF-8, `count` its codepoints |
| `IO` | `kv_io` (kIO.h) |
| `struct T` | `struct T`, its members in order |
| `enum T` of values | `struct T { uint8_t tag; union { ... } u; }` |
| `enum T` of names | C's `enum T` |
| `T?` | `struct _kv_opt_T`: tag 0 `none`, 1 `some` |
| `Result<T, E>` | `struct _kv_res_T_E`: tag 0 `ok`, 1 `err` |
| `Array<T>`, `$[T]` | `_kv_array_T`, of `KV_ARRAY` |
| `Dictionary<K, V>` | `_kv_dict_K_V`, of `KV_DICT` |
| `Set<T>` | `_kv_set_T`, of `KV_SET` |

- **A `let`** is `const` where C allows it; a `var` is not.
- **A type in a name** is spelled by its Kelvin name, `i64`, `String`,
  `point`, with `^` as `p`, `[` as `a`, `(` and `)` as `F` and `E`,
  and a space or a comma as `_`: `$[$[i64]]` is `_kv_array_Array_i64`,
  `Dictionary<String, i64>` is `_kv_dict_String_i64`.

### The growable types

```c
KV_ARRAY(int64_t, _kv_array_i64, KV_PLAIN_FREE, KV_PLAIN_COPY)
KV_ARRAY(kv_string, _kv_array_String, kv_string_free, kv_string_copy)
KV_DICT(kv_string, const uint8_t *, int64_t, _kv_dict_String_i64, KV_HASH_TEXT, KV_EQ_TEXT,
        KV_STORE_TEXT, KV_MISSING_TEXT, kv_string_free, kv_string_copy, KV_PLAIN_FREE, KV_PLAIN_COPY)
KV_SET(int64_t, int64_t, _kv_set_i64, KV_HASH_INT, KV_EQ_INT, KV_STORE_INT, KV_LK_INT,
       KV_PLAIN_FREE, KV_PLAIN_COPY)
```

- **Each type is made once,** by its macro, after the types of its
  elements and before its first use.
- **The element's free and copy** are the macro's last arguments:
  `KV_PLAIN_FREE` and `KV_PLAIN_COPY` for a value that owns nothing,
  else the type's own.
- **An Array's functions** are `A_at` (checked), `A_append`,
  `A_append_ref` (a borrowed Array's elements), `A_append_owned` (an
  Array an expression gave), `A_insert`, `A_remove`, `A_pop`, `A_from`,
  `A_zeros`, `A_slice`, `A_copy`, `A_reserve`, `A_clear`, `A_compact`,
  `A_free`, `A_take`, `A_assign`; `xs[i]` is `(*A_at(&xs, i))`.

### Enums with values, Optional and Result

```c
struct shape { uint8_t tag; union { struct point dot; double circle; } u; };
static inline struct shape _kv_shape_make_circle(double v);
static inline double _kv_shape_get_circle(struct shape self);   /* checked */
static inline double *_kv_shape_at_circle(const struct shape *self);
static inline void _kv_shape_set_circle(struct shape *self, double v);
```

- **The tag is the case's place** among the cases, from 0; a case of no
  value has `make` and `set` alone.
- **`get` and `at` check the tag,** and a wrong one ends the program,
  by `kv_case_fail`.
- **`T?` and `Result<T, E>`** are the same, as `struct _kv_opt_T` and
  `struct _kv_res_T_E`, their functions `_kv__kv_opt_T_make_some` and
  their kin, made once where first needed.

## Owners

A type that owns: `Bytes`, `String`, `IO`, an Array, a Dictionary, a
Set, a struct or an enum with values that holds one. Each has four
functions, by one rule.

| Function | Does |
|---|---|
| `F_free(T *p)` | frees what `*p` holds, and leaves it empty |
| `F_copy(const T *p)` | a new value, every owner in it copied |
| `F_take(T *p)` | `*p`, and `*p` empty: a move |
| `F_assign(T *p, T v)` | frees `*p`, then holds `v` |

- **`F` is the type's:** `kv_bytes`, `kv_string`, `kv_io`, `_kv_array_T`,
  `_kv_dict_K_V`, `_kv_set_T`, and `_kv_T` of a struct `T` or an enum
  `T` that owns, as `_kv_named_free`.
  - `kv_io_copy` ends the program: an IO is not copied.
  - Optional and Result have them as `_kv_` before their own names:
    `_kv__kv_res_i64_String_free`.
- **A local owner** is freed where its block ends, by C's `cleanup`
  attribute, on every way out: its `}`, `return`, `break`, `goto`.

  ```c
  __attribute__((cleanup(kv_string_free))) kv_string s = KV_STRING_OF("x");
  ```

- **`return s`** of a local owner is `return kv_string_take(&s);`, so
  the cleanup frees an empty one.
- **Passing by value moves:** the caller writes `F_take(&b)`; the
  callee takes it as `_kv_b_in` and binds it to `b`, its own, freed by
  cleanup.

  ```c
  int64_t eat(kv_bytes _kv_b_in)
  {
      __attribute__((cleanup(kv_bytes_free))) kv_bytes b = _kv_b_in;
      ...
  }
  ```

- **A borrow,** `&s`, is a `T *`.
- **A global owner** is `T g = {0};`, filled by the program, and freed
  at exit by `_kv_free_globals`, which `main` registers with `atexit`
  (#178).
- **An owner an expression gives,** where it is used and not bound,
  lives in a hidden local of a statement expression, freed with it
  (#187).

## Names

| Kelvin | C |
|---|---|
| `let f(x:i64)`, alone | `f` |
| `let f(x:i64)` overloaded, imported from a Kelvin file, or sharing a name with a C function the program calls before `f` is declared | `f__i64`, by its parameters' types; `f__void` of none; `__va` for `...` |
| `let T.m()`, a method | `T__m`; `T__m__i64` where methods of the name on `T` differ |
| a setter of `T.x` | `T__set_x` |
| `let T.cstr()` | `_kv_T_cstr`, `static inline` in each file |
| `static let T.of()`, a function of the type | `T__of` |
| `let +(a:T, b:T)` | `_kv_add_op__T__T`; `sub`, `mul`, `div`, `mod`, `eq`, `ne`, `lt`, `le`, `gt`, `ge`, and `neg` of `-x` |
| `let g()` inside `f` (#180) | `_kv_f_g` |
| an anonymous function | `_kv_main_fn`, `_kv_main_fn1`, ...: `_kv_`, the top-level declaration it is in, and `fn`; `_kv_fn0` outside any |
| `let main():i32` | `int32_t main(int _kv_argc, char **_kv_argv)` |
| `let main(argc:i32, argv:[cstr]):i32` | `int32_t main(const int32_t argc, char **const argv)` |

- **`_kv_` and `kv_` are reserved:** the runtime's names begin `kv_`
  and `KV_`, and kelvinc's hidden ones `_kv_`.
  - A hidden name is `_kv_` and what it comes from, then its kind:
    `_kv_tmp1`, `_kv_value0`, `_kv_n_text` (#38).
- **A program's own names** are as written; a Kelvin keyword cannot be
  one, and C's are Kelvin's keywords too.
- **A module's functions** are named by their types, as an imported
  file's are, so that a program's prototypes from its `.kh` meet them
  (#146).

## main and the runtime

```c
int32_t main(int _kv_argc, char **_kv_argv)
{
    kv_sys_init(_kv_argc, _kv_argv);       /* with <IO> or <OS> */
    atexit(_kv_free_globals);              /* with a global owner */
    ...
}
```

- **`kv_sys_init`** keeps the arguments for `SYS.argv`; it is
  `kOS.h`'s, so only a program that imports `<IO>` or `<OS>` calls it,
  with main's own names for them where it writes some.
- **A runtime failure,** an index out of range, a wrong case, a missing
  key, is `kv_exit_failure()`: the message on stderr, and exit
  status 1, or `abort()` with `KELVIN_ABORT` set (#174).
- **Text:**
  - `$"text"` is `KV_STRING_OF("text")`;
  - `s += x` is `KV_STRING_APPEND(&s, x)`, of text, a `kv_uchr`, a
    `kv_string *`, or a `kv_string` it frees;
  - `s.cstr` is `kv_bytes_cstr(&s.b)`;
  - `==` of two Strings is `kv_string_eq(&a, &b)`.
- **Printing:** `println(a, ...)` and `print` are the prelude's macros,
  each value printed by `_Generic` of its C type; a struct, an enum
  with values, an Array and their kin by `_kv_show_T`, which kelvinc
  writes.

## In practice

- **Read kelvinc's output:** `kelvinc --emit-c file.k` shows all of the
  above for a program, and is the reference where this document is
  silent.
- **kc follows it** (selfhost/kc.k, #204): the same head, the same
  `KV_ARRAY` and `_kv_array_T` names, `kv_string_take` on return, the
  same libraries. That is what lets its C link with `libkelvin` and
  `libkIO`.
